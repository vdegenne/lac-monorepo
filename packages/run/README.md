# lac-run

A simple one-value clipboard running on your local network (with WebSocket support.)

Use [`lac-api`](https://github.com/vdegenne/lac-monorepo/tree/main/packages/api) to easily manage the clipboard in your clients.

## Usage

```
npx lac-run [--port <override_default>]
```

or

```
npm i -g lac-run
lac-run [--port <override_default>]
```

(you can also just use `lac` in the second case.)

The server should now be running.
